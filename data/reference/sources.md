# 기준정보 참조 체계 (data/reference)

MedSupply Radar 시연 데이터셋의 기준정보(성분·대체군·품목 마스터)가 **어디까지 실제이고 어디부터 합성인지**를
명시한다. 이 구분은 시연 중 "이 숫자가 실제 제품인가"라는 질문에 즉답하기 위한 것이며,
데이터셋을 재현·검수하는 모든 후속 태스크의 전제다.

- 검증 테스트: `tests/data/test_reference_master.py`
- 스키마 계약: `medsupply/data/schema.sql` (ingredients / substitute_groups / items)

## 한 줄 요약

| 요소 | 실제 / 합성 | 근거 |
| --- | --- | --- |
| 성분명(한/영) | **실제** | 국제일반명(INN) 표기 |
| ATC 코드 | **실제** | WHO ATC/DDD Index 분류 체계 |
| 함량·제형·투여경로 | **실제 임상 관례** | 국내 병원 채택 규격에서 흔한 조합 |
| 품목명(제품명) | **합성** | 공급사 접두어 + 성분 표기 조합 |
| 공급사명 | **합성** | 실존 제약사와 무관 |
| 표준코드 | **합성** | `99` 프리픽스 13자리(실제 KD코드 체계와 충돌 회피) |
| 코드 체계(ING/SG/ITM) | **내부 합성** | 본 프로젝트 전용 연번 |

## ATC 코드 부여 방식

WHO Collaborating Centre for Drug Statistics Methodology의 **ATC/DDD Index** 분류 체계를 참조해
성분별 **5단계(7자리) ATC 코드**를 부여했다. 코드는 `해부학적 주계열(1) + 치료 주군(2) + 치료 세부군(1)
+ 화학적 세부군(1) + 화학물질(2)` 구조이며, 정규식 `^[A-Z]\d{2}[A-Z]{2}\d{2}$`을 만족한다.

부여 원칙:

1. **정확성 > 다양성**. 5단계 코드를 확신할 수 없는 성분은 목록에서 제외하고, 코드가 확실한 다른 성분으로
   대체했다. 성분 수를 채우기 위해 불확실한 코드를 추정해 넣지 않았다.
2. **성분 1종 = ATC 코드 1개**. 성분 마스터 안에서 ATC 코드는 유일하다(중복 시 분류 오류로 간주하고
   테스트가 실패한다).
3. **품목의 `atc_code`는 성분의 값을 그대로 복제**한다. schema.sql에서 items.atc_code는 조회 편의를 위한
   비정규화 컬럼이므로, 성분 마스터가 단일 진실 원천이고 품목은 파생값이다.
4. 다중 성분 복합제(아목시실린·클라불란산칼륨)는 WHO ATC의 복합제 세부군(`J01CR`)을 따랐다.
5. **ATC 코드는 제형·투여경로에 따라 갈린다 — 채택한 규격의 코드를 쓴다.** ATC는 성분만으로 결정되지
   않는다. 같은 성분이라도 전신 경구용과 흡입용이 다른 세부군에 배정되는 경우가 있으므로, 본 마스터는
   **실제로 채택한 제형·경로에 맞는 코드**를 부여한다. 대표 사례:
   - 살부타몰: 흡입용은 `R03AC02`지만 본 마스터는 경구 정제·시럽만 채택했으므로 전신 경구용
     `R03CC02`를 쓴다.
   - 테오필린: 경구 서방정 규격이므로 잔틴계 `R03DA04`.
   - 염화나트륨: 0.9% 수액백 기준이므로 수액용 `B05BB01`(주사액 첨가 농축액 `B05XA03`이 아니다).

   같은 이유로, 경구 제형이 존재하지 않는 성분(흡입 전용 스테로이드 등)은 경구 품목을 만들지 않고
   목록에서 제외했다.
6. **투여경로 근사가 필요한 경우**: 본 데이터셋의 `route`는 아래 "값 규약" 절의 5값으로 제한되며,
   여기에 없는 경로(설하 등)는 가장 가까운 값으로 근사한다(예: 니트로글리세린 설하정 → `경구`).
   근사한 경우에도 ATC 코드는 원칙 5에 따라 실제 채택 규격 기준으로 부여한다.

## 값 규약 — form / route

`medsupply/data/schema.sql`의 `items.form`·`items.route`에는 **CHECK 제약이 없다**(자유 TEXT). 아래 집합은
schema 계약이 아니라 **본 프로젝트의 데이터 규약**이며, 그 강제는 `tests/data/test_reference_master.py`가
담당한다. 값을 늘리려면 이 문서와 테스트를 같이 고쳐야 한다.

- `form` (8값): `정제` · `캡슐` · `시럽` · `주사` · `바이알` · `서방정` · `산제` · `패치`
- `route` (5값): `경구` · `정맥주사` · `근육주사` · `피하` · `외용`

`피하`는 픽스 라운드 1에서 추가했다. 에녹사파린처럼 피하 투여가 표준인 품목을 `정맥주사`로 근사하면
대체군 키(`route` 포함)가 임상적으로 틀린 묶음을 만들 수 있기 때문이다.

## 합성 코드 규칙

### 표준코드 (`items_master.standard_code`)

**13자리 숫자, 항상 `99`로 시작한다.** 국내 의약품 표준코드(KD코드)는 `8806…` 형태의 GS1 계열 번호를 쓰므로,
`99` 프리픽스는 실존 코드와 절대 충돌하지 않는 합성 표식이다. 검증 정규식은 `^99\d{11}$`.

자리 구성(자기설명적):

```
99  001  001  00001
│   │    │    └─ 품목 연번 5자리 (ITM-0001 → 00001)
│   │    └────── 대체군 연번 3자리 (SG-001 → 001)
│   └─────────── 성분 연번 3자리 (ING-001 → 001)
└─────────────── 합성 표식 프리픽스
```

품목 연번이 코드에 포함되므로 표준코드는 전역 유일하다. 체크디지트는 두지 않는다(합성 코드임을 숨기지
않기 위해 실제 GS1 체크디지트 규칙을 흉내 내지 않는다).

### 연번 체계

| 코드 | 형식 | 범위 | 비고 |
| --- | --- | --- | --- |
| `ingredient_code` | `ING-###` | ING-001 ~ ING-048 | 결번 없는 연번 |
| `substitute_group_id` | `SG-###` | SG-001 ~ SG-073 | 결번 없는 연번 |
| `item_id` | `ITM-####` | ITM-0001 ~ ITM-0124 | 결번 없는 연번 |

세 코드 모두 성분 순서 → 대체군 순서 → 품목 순서로 정렬되어 있어, 파일을 눈으로 훑어도 소속 관계가 보인다.

### 대체군 정의 규칙

**동일 성분 + 동일 함량 + 동일 제형 + 동일 투여경로 = 하나의 대체군**이다. 네 값 중 하나라도 다르면 다른
그룹이며, 그룹 키 `(ingredient_code, strength, form, route)`는 전역 유일하다. 품목의 네 값은 소속 그룹의 값과
정확히 일치해야 한다(테스트 강제).

이 규칙 때문에 "함량이 다른 같은 성분"은 **자동 대체 후보가 아니다**. 예를 들어
아세트아미노펜 500mg 정제 경구(SG-001, 3품목)와 아세트아미노펜 650mg 서방정 경구(SG-002, 1품목)는 별도
그룹이며, 후자는 화면에서 "조건 불일치 — 처방 변경·임상 검토 필요" 후보로만 제시된다.

## 품목명·공급사가 합성이라는 점

- **품목명은 실존 상표명이 아니다.** `공급사 접두어 + 성분 표기(일부 축약) + 제형 + 함량` 조합으로 만든
  합성 명칭이다(예: `한빛덱시부프로펜정 300mg`, `대한목시실캡슐 500mg`). 실제 시판 제품과 이름이 비슷해
  보이더라도 동일 제품을 지칭하지 않는다.
- **공급사 9사는 모두 가공의 회사명이다.** 기존 프로토타입에서 이어받은 5사(한빛제약·대한제약·유니메드·
  메디팜·그린바이오)와 이번에 추가한 4사(서울파마·미래바이오·누리팜·한결바이오) 모두 실존 제약사·수입사와
  무관하며, 특정 기업의 공급 능력·품질을 시사하지 않는다.
- **예외적으로 이름을 보존한 품목**: 기존 UI 데모(`medsupply/views/_demo.py`, `medsupply/views/review.py`)가
  쓰던 `아세트아미노펜정 500mg`, `세프트리악손주 1g`, `아목시실린캡슐 500mg`, `덱시부프로펜시럽`,
  `메트포르민정 500mg`, `아토르바스타틴정 10mg`, `아세트아미노펜서방정 650mg`은 시연 서사 연속성을 위해
  기존 명칭·공급사 매핑을 그대로 유지했다. 이들 역시 성분명 기반의 일반명 표기이지 상표명이 아니다.

## 필수의약품 플래그(`is_essential`)

국가필수의약품 지정이 **성분 단위**로 이루어지는 실제 관례를 따라, 동일 성분의 모든 품목에 같은 값을 부여했다
(공급사별로 값이 갈리지 않는다). 응급·중환자·감염·수액 계열 11개 성분을 필수로 지정했으며, 전체 품목의
약 30%에 해당한다.

## 데이터가 아닌 것

이 파일들은 **특정 의료기관의 실제 채택 목록이 아니고**, 실제 수급 현황·재고·가격 정보를 담지 않는다.
치료 목적의 대체 판단 근거로 사용할 수 없으며, 대체군은 "행정적으로 동일 규격"이라는 뜻이지
"임상적으로 상호 교환 가능"을 뜻하지 않는다.

## 품절 시나리오 참조 사례

`data/scenarios/scenario_config.yaml`의 각 시나리오는 `reference` 키로 아래 사례 중 하나와
1:1로 연결된다. 아래 사례는 **국내 의약품 수급 불안정과 관련해 폭넓게 알려진 전개 패턴**을
사건명·시기·전개 패턴 요약 수준으로 정리한 것이며, **특정 회사명·정확한 날짜·수치를 단정하지
않는다**. `scenario_config.yaml`의 구체적 배수·지연일·날짜는 이 패턴을 참고해 감지 가능
범위를 겨냥해 설계한 값이지, 특정 사건의 실측치를 인용한 것이 아니다(각 시나리오 항목의
"강도" 주석에 설계 의도를 병기했다). 상세 배분 근거는 태스크 보고서
(`.superpowers/sdd/2026-08-19-medsupply-master-plan/briefs/task-S03-report.md`)를 참고한다.

### 2022-2023 호흡기감염병 동시유행기 항생제·해열제 수요급증

- **시기**: 2022년 말~2023년 초(코로나19-인플루엔자 동시유행, 이른바 '트윈데믹' 시기)
- **전개 패턴**: 호흡기 감염병 환자가 단기간에 몰리면서 해열진통제(아세트아미노펜 계열)와
  소아·성인 항생제 처방이 평시 대비 수주간 급증했고, 일부 품목은 약국·의료기관에서 일시적
  구득난을 겪었다고 다수 보도되었다. 정부가 생산 확대를 요청하는 등, 수요급증형 수급 불안의
  대표 패턴으로 흔히 인용된다.
- **시나리오 반영**: 수요가 1~4주에 걸쳐 완만~급격히 증가한 뒤 일정 기간 높은 수준을
  유지하는 형태(`ramp_days` + `sustain: true`)로 단순화해 반영했다(SC-001·SC-002·SC-003).

### 환절기 알레르기·천식질환 치료제 계절 수요증가

- **시기**: 매년 봄·가을 환절기(황사·꽃가루 시기)에 반복되는 계절 패턴
- **전개 패턴**: 알레르기 비염·천식 치료제(류코트리엔 조절제, 기관지확장제 등) 수요가
  환절기마다 평시보다 완만하게 늘어나는 계절성이 관행적으로 알려져 있다. 감염병 동시유행형
  수요급증보다 증가 폭이 작고 기간이 길게 분산되는 것이 특징이다.
- **시나리오 반영**: 상대적으로 긴 `ramp_days`와 낮은~중간 `peak_multiplier`로 설계해,
  감염병형 수요급증보다 완만한 패턴을 표현했다(SC-004·SC-005).

### 제조소 품질·설비 점검에 따른 공급중단 공고 관행

- **시기**: 상시(특정 사건이 아닌 반복되는 관행)
- **전개 패턴**: 국내 의약품 제조사가 GMP 점검·설비 교체·품질 이슈 등으로 특정 품목의 생산을
  일시 중단하면, 의약품 통합정보시스템 등에 '공급중단' 공고를 등록하는 것이 관행이다. 공고
  시점에 재개 예정일이 미정으로 남는 경우와, 이후 별도 공고로 특정 시점이 제시되는 경우가
  모두 흔하다.
- **시나리오 반영**: `halt_start_date` 이후 입고가 없는 상태를 기본으로 하고,
  `expected_restart_date`를 `null`(미정) 또는 향후 시점으로 혼합 배치했다
  (SC-006·SC-007·SC-010).

### 원료의약품 수급 차질형 공급중단

- **시기**: 상시(특정 사건이 아닌 반복되는 구조적 취약점)
- **전개 패턴**: 원료의약품(API)을 해외 수입에 의존하는 완제품은 원료 공급사의 사정으로
  원료 수급이 막히면 완제품 생산도 함께 중단되는 구조적 취약성이 있다고 알려져 있다. 특히
  주사제·수액처럼 소수 제조사가 공급을 담당하는 품목에서 이런 유형의 공급중단이 반복적으로
  지적된다.
- **시나리오 반영**: 다른 공급중단 사례보다 `halt_start_date`를 이르게 잡아(경과 기간을
  길게) 원료 차질형이 상대적으로 장기화되는 경향을 반영했다(SC-008·SC-009).

### 원료의약품 수입통관·물류 지연에 따른 입고 지연 관행

- **시기**: 상시(특정 사건이 아닌 반복되는 관행)
- **전개 패턴**: 원료·완제 의약품 수입 과정에서 통관 절차, 국제 물류·운송 일정 차질로
  예정된 입고일보다 실제 입고가 지연되는 사례가 흔히 보고된다. 지연 폭은 수일에서 길게는
  2주 이상까지 다양한 것으로 알려져 있으며, 지연과 함께 입고량이 예정보다 줄어드는 경우도
  있다.
- **시나리오 반영**: `expected_date` 대비 `delay_days`를 감지 임계(3일) 근접치부터
  15일까지 다양하게 배치했고, 일부는 `qty_ratio`를 1.0 미만으로 설정해 지연과 물량축소가
  겹치는 경우를 표현했다(SC-011~SC-015).

### 감염병 유행기 수요급증-제조차질 복합 품절

- **시기**: 2022-2023 동시유행기 전후 정황
- **전개 패턴**: 수요급증 시기와 제조사의 생산·공급 차질이 겹치면 품절이 더 빠르게
  심화된다는 점은 여러 품절 사례 보도에서 공통적으로 지적되는 정황이다. 한쪽 요인만 있을
  때보다 소진이 앞당겨지는 복합 위험 패턴으로 흔히 인용된다.
- **시나리오 반영**: `demand_surge`와 `supply_halt` 서브시나리오를 시간차를 두고
  `sub_scenarios`로 중첩해, 수요증가가 먼저 시작되고 이어서 공급까지 끊기는 순서로
  설계했다(SC-016·SC-017·SC-019).

### 공급중단 후 대체입고 지연 이중 차질

- **시기**: 상시(특정 사건이 아닌 반복되는 관행)
- **전개 패턴**: 기존 공급사가 공급을 중단하면 의료기관·약국이 대체 조달을 시도하지만,
  대체 경로의 입고 역시 지연되면서 이중으로 품절 위험이 커지는 경우가 있다고 알려져 있다
  (공급망 전반의 병목이 특정 제조사에 국한되지 않는 경우 특히 그렇다).
- **시나리오 반영**: `supply_halt`와 `delivery_delay` 서브시나리오를 함께 배치해, 1차
  공급 중단과 대체(재발주) 입고 지연이 겹치는 상태를 표현했다(SC-018·SC-020).
