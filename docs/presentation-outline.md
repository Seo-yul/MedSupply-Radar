# MedSupply Radar 발표자료 아웃라인 (데모 3 · 최종 시연)

슬라이드 13장 구성. 제목·핵심 메시지만 담고 디자인은 다루지 않는다. **수치는 슬라이드에
직접 적지 않고 출처 경로만 남긴다** — 실제 값은 발표 직전 `docs/verification-report.md`와
표준 스냅샷(`data/medsupply.db`)에서 그대로 인용한다(이 문서와 별도 유지 시 값이
어긋나는 것을 막기 위함). 발표 진행 스크립트와 화면 조작 순서는 `docs/demo-script.md`를
그대로 따른다.
