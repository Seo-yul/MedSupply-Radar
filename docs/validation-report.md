## 9. 한계와 해석

### 합격선 관련 주의사항

본 리포트의 합격선은 정성적 기준을 반영하며, 최종 결정은 도메인 전문가 검토를 거쳐야 한다. 각 지표는 독립적으로 평가되었으며, 시스템 전체의 임상적 유효성은 통합 검토 후 판정된다.

### 측정 신뢰도

- 데이터셋: 콘텐츠 해시로 재현성 보증
- 파라미터: analytics_params.toml 고정 적용
- LLM 평가: 다계열 Judge 모델 사용
